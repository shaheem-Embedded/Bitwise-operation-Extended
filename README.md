Bitwise Operations-Extended Applications for Embedded based platform
-----------------------------------------------------------------------------
> Bit wise Compression.
  This helps to extract specific positioned data from 16 bit register and recontruct an 8 bit register,Bit exctraction can be done based on the extracting position      required,
  here i have used extraction from even bits.
> Bit wise Spreading.
  This helps to spread the 8 bit register value to a 16 bit register value by adding '0' to every interleaving bits and reconstruct a 16 bit register,(Applicability     in parity checking processes)
> Bit wise set and clear operations with and 8 bit regiter:
  This helps the user to set or clear the specified bit in an 8 bit rgister,useful in Embedded Register access and modifications.
  Also included method to set/Clear a specific Kth bit as per requirement.
